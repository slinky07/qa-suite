# Smoke QA

Use the `qa-suite` skill.

Orchestrate `smoke-qa` only. If the host supports subagents/delegation,
dispatch Smoke as an independent QA subagent.

Freeze the smoke execution in a dispatch manifest before dispatch. Follow
`qa-context.md` and platform startup checks, then write the exact report and
digest-bound proposal sidecar. Complete `inventory -> review -> materialize ->
reconcile -> verify` with the canonical helper before synthesis, transport only
bounded draft decision tasks, and use the verifier's persistence state and
exact human commit handoff.
